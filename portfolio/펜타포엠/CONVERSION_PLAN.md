# 포트폴리오 퍼블리싱 정리 계획

1. 스애띠밸리의 `HTML + css/ + js/ + images/ + fonts/` 구성을 기준으로 펜타포엠도 통일한다.
2. 펜타포엠 HTML은 루트 `분류_페이지.html`로 옮기고 내부 링크·이미지·스크립트 경로를 모두 상대 경로로 수정한다. 메인은 `index.html`이다.
3. 기존 정적 페이지 경로·렌더링 검사를 먼저 실행하고, 변경한 구조에 맞춰 검증 도구도 수정한다.
4. Java 소스·서버 설정·Maven·빌드 결과·IDE 설정·최초 변환 도구를 제거한다. 원본 보관을 전제로 한 안내도 제거한다.
5. 두 프로젝트의 파일 참조와 JS를 검사한다. GitHub Pages에는 정적 파일만 올릴 수 있도록 구성한다.

사용자 요청에 따라 Java 원본은 이 프로젝트 내부에 남기지 않는다. Git 원격 연결·공개 배포는 이번 작업에 포함하지 않는다.
