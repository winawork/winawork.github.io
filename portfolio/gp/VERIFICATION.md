# 검증 기록

- 54개 독립 화면 + pages.html 생성.
- 전체 HTML/CSS/폰트/동영상 경로, JSP·서버 경로 잔여 검사 통과.
- preview.js 문법 검사 통과.
- 브라우저에서 메인 영상 표시, 고객센터 샘플 목록, 비밀글 확인→샘플 상세, 목록 복귀→작성 화면 이동 확인.
- 영문 메인 및 영문 오시는 길 페이지 이동·주소 표시 확인.
- 원본에서 참조하지 않는 관리자 업로드 파일은 배포 대상에서 제외.
- 실제 게시판·접수·인증은 퍼블리싱 범위에 포함하지 않음.
- 모든 화면·기기 크기의 원본 대비 픽셀 비교 및 원격 배포는 수행하지 않음.
