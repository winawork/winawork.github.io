# 스에떼밸리 퍼블리싱

`index.html`을 더블 클릭하면 메인 화면이 열립니다. `main.html`도 유지했습니다.
`pages.html`에서 원본 9개 화면을 모두 확인할 수 있습니다.

HTML, CSS, JavaScript, 이미지, 폰트만으로 동작하며 설치나 빌드, 서버가 필요하지 않습니다.
이미지·폰트·메뉴는 상대 경로이므로 GitHub Pages의 저장소 하위 경로에서도 사용할 수 있습니다.
이 폴더 내용을 Git 저장소의 루트로 올리고 GitHub Pages에서 해당 브랜치의 루트를 게시하면 됩니다.

관심고객등록은 화면 미리보기입니다. 입력 정보는 저장하거나 전송하지 않으며 등록 버튼은 완료 화면으로만 이동합니다.
인스타그램·블로그는 원본에 실제 주소가 없어 링크 미제공 안내를 표시합니다.
기존 디자인을 유지했으며, 원본에 없는 Pretendard Black 폰트 선언과 사용하지 않는 Slick 테마 CSS만 제거했습니다.
폰트 900 굵기는 브라우저가 제공된 가장 가까운 굵기로 표시합니다.

경로 검사: `python3 scripts/check-static.py`
