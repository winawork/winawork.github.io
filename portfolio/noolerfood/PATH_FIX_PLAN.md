# 경로 수정 계획

- 기존 HTML 디자인을 유지하고 /images 절대 경로를 images 상대 경로로 수정한다.
- 이미 존재하는 회사·브랜드·제품·새소식·문의 화면을 헤더와 전체 메뉴에 연결한다.
- 메인 상세보기와 게시판 상세·목록 경로를 연결한다. 미제공 외부 주소는 임의 연결하지 않고 안내한다.
- GitHub Pages 루트 진입을 위해 index.html을 추가한다.
- 사용하지 않는 원격 Swiper 참조는 제거한다. 추가 라이브러리는 설치하지 않는다.
- 모든 HTML/CSS 로컬 참조 및 JS 문법과 브라우저 메뉴 이동을 확인한다.
