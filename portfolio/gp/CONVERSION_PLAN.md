# GP 정적 퍼블리싱 전환 계획

1. JSP 공통 헤더·푸터·Tiles 레이아웃과 메시지 번역을 각 HTML에 포함한다.
2. HTML을 루트에 분류_페이지.html로 배치하고 css/js/images/fonts/video 경로는 상대 경로로 바꾼다.
3. 기존 디자인과 국문·영문 화면을 유지한다. 게시판은 명시적인 샘플, 폼은 전송 없는 미리보기로 바꾼다.
4. 파일 경로·JSP 잔여 문법·JS 문법 및 브라우저 메뉴 이동을 확인한다.
5. Java/JSP/Maven/빌드/IDE 파일과 중첩 Git 정보를 원본 백업 후 프로젝트에서 제거한다. 상위 Git 저장소는 변경하지 않는다.
